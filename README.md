# Technical Test - Klark

Welcome to the technical test of [Startup Name]!

The purpose of this exercise is to evaluate your skills in JavaScript (JS) and Python development, as well as your knowledge of Docker containerization. Your mission is to correct the issues in the provided code that prevent the tests from passing. You may also fix typos or syntax errors if necessary. Additionally, any improvements to algorithms, security, or efficiency are welcome.

## General Instructions

1. Clone this Git repository to your local machine.

2. You will find two distinct folders:

   - `crm`, which contains problems related to JavaScript.
   - `klarkAI`, which contains problems related to Python, specifically related to artificial intelligence (AI).

3. In each folder, you will find source code files containing problems and corresponding unit tests.

4. Your task is to fix the issues in the source code so that the unit tests pass successfully. The tests are your reference to determine if your code is functioning correctly.

5. You can also enhance code quality by optimizing algorithms, strengthening security, or improving code readability. However, make sure not to alter the expected behavior of the tests.

6. Use Docker to run the unit tests. We provide a ready-to-use Dockerfile in each folder. The necessary dependencies are already configured in these files.
